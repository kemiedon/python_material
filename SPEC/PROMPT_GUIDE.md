# AI 指令規範書

## 語言規定

- **必須使用繁體中文** 進行所有對話和文檔編寫

## 提交規範

- 每當完成一個任務後，自動 push 到 repository
- Commit 訊息按照以下格式命名：`日期-時間-版本[編號]`
  - 範例：`2025-11-22-17:20:46-v1[建立專案結構]`
  - 日期格式：YYYY-MM-DD
  - 時間格式：HH:MM:SS（24 小時制）
  - 版本編號：v1, v2, v3...（按照當日提交次數遞增）
  - 編號說明：用方括號括起來的簡要說明
- 每次 commit 說明需要整理該次更新的內容重點

## 教材整理 Prompt

當整理教材內容時，請遵循以下規則：

1. **Markdown 格式**：使用標準 Markdown 語法
2. **移除 emoji**：所有表情符號都應移除
3. **統一副標題**：
   - 使用「生活化範例」取代「用生活解釋」或「生活例子」
   - 使用「練習題」取代「練習」或其他變體
4. **程式範例**：每個單元需要 2 個程式範例檔
5. **AI 協助學習 Prompt**：
   - 每個單元之後加入「AI 協助學習 Prompt」區塊
   - 提供具體的 prompt 讓學生可以回家練習及複習
   - prompt 應該針對該單元的重點內容
