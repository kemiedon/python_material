- **必須使用繁體中文** 進行所有對話和文檔編寫

## 提交規範

- 每當完成一個任務後，自動 push 到 repository
- Commit 訊息按照以下序列命名：
  - 第 1-26 個：`a`, `b`, `c`, `d`, ... `z`
  - 第 27-52 個：`aa`, `ab`, `ac`, ... `az`
  - 第 53-78 個：`ba`, `bb`, `bc`, ... `bz`
  - 依此類推

## 教材整理 Prompt

當整理教材內容時，請遵循以下規則：

1. **Markdown 格式**：使用標準 Markdown 語法
2. **移除 emoji**：所有表情符號都應移除
3. **統一副標題**：
   - 使用「生活化範例」取代「用生活解釋」或「生活例子」
   - 使用「練習題」取代「練習」或其他變體
4. **程式範例**：每個單元需要 2 個程式範例檔
5. **AI 協助學習 Prompt**：
   - 每個單元之後加入「AI 協助學習 Prompt」區塊
   - 提供具體的 prompt 讓學生可以回家練習及複習
   - prompt 應該針對該單元的重點內容
